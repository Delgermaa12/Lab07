## Хэсэг E: Дүгнэлт

Хамгийн үр дүнтэй аялал нь Couch Potato байв, учир нь хоосон болон буруу оролт өгөхөд маягтын шалгалтын хэд хэдэн согог (BUG-01, 02, 06) богино хугацаанд олдсон. Fed-Ex аялал нь өгөгдөл хүснэгтэд хэрхэн харагдаж, тоолуурт хэрхэн тоологдохыг шалгахад тусалж BUG-03, BUG-08-г илрүүлсэн. Saboteur аялалд curl ашиглан API-г шалгаж BUG-04 (буруу JSON дээр 200 OK) болон BUG-07-г (/old → 500) нотолсон. Charter-аас гадуур санамсаргүй олдсон зүйл бол Устгах товчийн өнгө (BUG-09) байв. Мөн нэмсний дараа маягтын талбар цэвэрлэгдэхгүй байгаа зан төлөв ажиглагдсан боловч спецификацид байхгүй тул согогоор тооцоогүй. Шалгагдаагүй үлдсэн зүйл бол "Нийт ном" тоолуур зөрөх яг нөхцөл (аль үйлдлийн дараа зөрдөг) бөгөөд дараагийн session-ий charter болгоно. Мөн Устгах үйлдлийн дараах тоолуурын зан төлөвийг тусад нь шалгана. Playwright автомат тест нь BUG-01, 02, 03, 04, 05, 07, 08-г баригдах байсан, учир нь эдгээр нь тодорхой оролт, хүлээгдэх утга, статус кодтой. BUG-09 (товчийн өнгө) болон өгөгдлийн хэт урт утга хүснэгтийг хэрхэн харагдуулах зэрэг нь автомат тестэд тусгайлан бичихгүй бол хүний нүдээр л олдох байсан. Иймд автомат тест ба exploratory тест хоёр бие биенээ нөхөх ёстой гэж дүгнэв.
