# BUG-04: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш 200 OK буцаана

Орчин:  Уншлагын жагсаалт v2.0, curl 8.14.1, Firefox 153.0, Debian GNU/Linux 13 (trixie), 2026-10-21
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. `node app.js`-ийг шинээр асаа.
2. Өөр терминалд дараах командыг ажиллуул:

   ```
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":'
   ```

3. Хариуны эхний мөрийг хар: `HTTP/1.1 200 OK`. Хариуны биет хоосон.
4. Мөн `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'` ажиллуулахад ижил `HTTP/1.1 200 OK` буцна.

Хүлээгдэж байсан: Спецификац: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
Бодит үр дүн:     Эвдэрсэн JSON (`{"title":`) болон JSON биш текст хоёрт хоёуланд нь сервер `HTTP/1.1 200 OK` буцааж, алдааны мэдээлэл өгөөгүй. Хүсэлт амжилттай боловсруулагдсан мэт харагдана.
Ноцтой байдал: Major, API-г ашигладаг клиент буруу хүсэлтээ амжилттай гэж ойлгоно.
